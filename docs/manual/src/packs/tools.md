# Tools

A tool pack installs a language or another tool into the sandbox. It
also allows the hosts that the tool needs, for example its package
registry.

- [Docker](./tools/docker.md) (`docker`)
- [Git](./tools/git.md) (`git`)
- [mise](./tools/mise.md) (`mise`)
- [Node.js](./tools/nodejs.md) (`nodejs`)
- [Python](./tools/python.md) (`python`)
- [Rust](./tools/rust.md) (`rust`)

An `allow-*` arg allows the package registry of the tool. Set it to
`false` to block the registry.
